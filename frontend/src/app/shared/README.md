# Shared Module

This folder contains reusable components, directives, and pipes that are used across multiple features of the application.

## Contents
- **Components**: UI components like buttons, cards, modals (dumb components).
- **Directives**: Custom directives for behavior.
- **Pipes**: Custom data transformation pipes.
- **Models**: Shared data models and interfaces.

**Rule**: Items in this module should not depend on any specific feature module.
